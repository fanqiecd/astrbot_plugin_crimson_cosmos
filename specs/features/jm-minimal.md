# JM 本子最小功能 — 功能需求说明书

## 1. 背景与价值

**为什么做**：现有插件能获取图片和查询 Jable，但不能搜索、查看或下载 JM 本子。

**做成什么样**：用户可在已允许的会话中完成 JM 搜索、详情查看、热门浏览和 ZIP 下载。

## 2. 范围

### 本次做

- `/jm 搜索 <关键词> [页码]`
- `/jm 详情 <ID>`
- `/jm 热门 [日/周/月] [页码]`
- `/jm 下载 <ID>`，下载后打包普通 ZIP 并发送
- JM 域名、客户端类型、代理、重试和并发配置
- 复用现有会话权限，发送完成后按配置清理文件

### 本次不做

- 登录、收藏夹和 Cookie 持久化
- 更新订阅、主动推送和每日配额
- PDF、长图和加密 ZIP
- JM 下载进度消息和增量章节下载

## 3. 用户与故事

**涉及角色**：已获准使用插件的群聊或私聊用户

| 编号 | 用户故事 | 关联 AC |
|------|---------|---------|
| US-001 | 作为用户，我想搜索和浏览 JM 本子，以便找到目标 ID | AC-001, AC-002, AC-003 |
| US-002 | 作为用户，我想下载指定本子，以便在聊天中收到 ZIP 文件 | AC-004 |

## 4. 需求详述

### 4.1 核心流程

1. 用户在允许的会话中输入 `/jm` 子命令。
2. 插件校验参数并获取 JM 数据。
3. 插件返回文本、封面或 ZIP 文件；失败时返回明确提示。

### 4.2 交互规则

- 搜索和热门列表每页最多显示配置的结果数量。
- 下载成功后发送普通 ZIP；开启自动清理时删除下载目录和 ZIP。
- 未安装 JM 依赖时不影响插件加载，只在使用 `/jm` 时提示。

### 4.3 业务规则

| 编号 | 规则 |
|------|------|
| BR-001 | `/jm` 服从现有群聊白名单和私聊开关。 |
| BR-002 | 本子 ID 必须为纯数字。 |
| BR-003 | 热门周期只接受日、周、月及对应英文值。 |
| BR-004 | 本次只生成普通 ZIP。 |

## 5. 验收标准

### 5.1 正常流程 (Happy Path)

- [ ] **AC-001**: 搜索本子
  - **Given** 用户位于允许的会话且 JM 服务可用
  - **When** 用户输入 `/jm 搜索 关键词 2`
  - **Then** 插件返回第 2 页的本子 ID、标题和标签列表

- [ ] **AC-002**: 查看详情
  - **Given** 用户位于允许的会话且本子存在
  - **When** 用户输入 `/jm 详情 <ID>`
  - **Then** 插件返回标题、作者、标签和章节数，并在可用时附带封面

- [ ] **AC-003**: 查看热门
  - **Given** 用户位于允许的会话且 JM 服务可用
  - **When** 用户输入 `/jm 热门 周 1`
  - **Then** 插件返回周榜第 1 页的本子 ID 和标题

- [ ] **AC-004**: 下载本子
  - **Given** 用户位于允许的会话且本子存在
  - **When** 用户输入 `/jm 下载 <ID>`
  - **Then** 插件发送包含该本子图片的普通 ZIP 文件

### 5.2 边界与异常 (Edge & Error Cases)

- [ ] **AC-005**: 依赖缺失
  - **Given** 未安装 jmcomic
  - **When** 用户使用任意 `/jm` 子命令
  - **Then** 插件提示安装 jmcomic，其他插件功能仍可使用

- [ ] **AC-006**: 参数无效
  - **Given** 用户位于允许的会话
  - **When** 用户提交空关键词、非数字 ID、非法周期或无效页码
  - **Then** 插件返回对应命令用法且不发起获取

- [ ] **AC-007**: 获取失败
  - **Given** JM 返回错误或网络不可用
  - **When** 用户使用 `/jm` 子命令
  - **Then** 插件返回安全的失败提示，不泄露异常堆栈

### 5.3 业务规则验证 (Business Rules)

- [ ] **AC-008**: 会话权限生效 ← BR-001
  - **Given** 当前群不在白名单或私聊未开启
  - **When** 用户使用 `/jm`
  - **Then** 插件不返回任何结果

- [ ] **AC-009**: 下载产物受限 ← BR-002, BR-004
  - **Given** 用户输入合法数字 ID
  - **When** 下载完成
  - **Then** 只生成普通 ZIP，不生成 PDF、长图或加密文件
